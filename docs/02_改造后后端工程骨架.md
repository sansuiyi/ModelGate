        for (GlobalModelEntity e : entities) {
            ModelCatalogItem item = objectMapper.readValue(e.getCustomConfig(), ModelCatalogItem.class);
            if (!e.isEnabled()) item.setEnabled(false);
            map.put(e.getModelName(), item);
        }
        return map;
    }

    public Optional<ModelCatalogItem> getModelInfo(String name) { ... }
    public String getOpenRouterId(String name) {
        return getModelInfo(name).map(ModelCatalogItem::getOpenRouterId).orElse(name);
    }

### 6.2 `PromptClassifier` + `HeuristicClassifier`（源 classifier.py）

```java
@Service
public class PromptClassifier {
    private final HeuristicClassifier heuristic;
    private final LocalInferenceClient inference;   // 可选：独立 GGUF 服务
    private boolean modelLoaded;

    public String classify(String prompt) {
        String stripped = prompt.strip();
        long words = Arrays.stream(stripped.split("\\s+")).filter(w -> !w.isBlank()).count();

        // 短 prompt 快速判 simple（与源一致）
        if (words <= 5 && !hasKeyword(stripped, List.of("analyze","build","create","write","code","implement"))) {
            return "simple";
        }
        // 模型可用则用模型；否则启发式
        if (modelLoaded) {
            try { return inference.classify(prompt); }
            catch (Exception e) { log.warn("LLM classify failed, fallback to heuristic"); }
        }
        return heuristic.classify(prompt);
    }

    private boolean hasKeyword(String text, List<String> kws) {
        String lower = text.toLowerCase(Locale.ROOT);
        return kws.stream().anyMatch(lower::contains);
    }
}
```

`HeuristicClassifier` 直接把 `heuristic_classify()` 的三张关键词表（complex / medium / simple + code_signals）与打分顺序 1:1 平移，返回 `simple|medium|complex`。

> 分类状态 `_model_loaded` 在启动时由 `ClassifierInitializer`（`ApplicationRunner`）加载：读取 `ClassifierProperties` 决定是否连接独立推理服务，加载失败自动置 `modelLoaded=false` 并回退启发式——与源行为完全一致。

### 6.3 `RoutingEngineService`（源 router_engine.py，核心）

```java
@Service
public class RoutingEngineService {

    private static final Map<String, Integer> TIER_QUALITY = Map.of("simple",1,"medium",2,"complex",3);
    private static final Map<String,String> TIER_ESCALATION = Map.of(
        "simple","medium", "medium","complex", "complex","complex");

    private static final Map<String,List<String>> DEFAULT_CANDIDATES = Map.of(
        "simple",  List.of("gpt-4o-mini","claude-haiku","gemini-2.0-flash"),
        "medium",  List.of("claude-sonnet","gpt-4o"),
        "complex", List.of("gemini-2.5-pro","claude-sonnet"));

    private final PromptClassifier classifier;
    private final ModelCatalogService catalog;
    private final GlobalModelRepository modelRepository;

    public RoutingDecision route(CustomerProfile profile, String prompt, String tierOverride) {
        String classification = (tierOverride != null) ? tierOverride : classifier.classify(prompt);

        List<String> candidates = profile.routingPreferences().getOrDefault(classification, List.of());
        if (candidates.isEmpty()) candidates = DEFAULT_CANDIDATES.getOrDefault(classification, List.of("gpt-4o-mini"));

        Set<String> enabled = modelRepository.findAll().stream()
                .filter(GlobalModelEntity::isEnabled)
                .map(GlobalModelEntity::getModelName)
                .collect(Collectors.toSet());

        Map<String,String> eliminated = new LinkedHashMap<>();
        List<String> valid = new ArrayList<>();

        for (String name : candidates) {
            if (!enabled.contains(name)) { eliminated.put(name, "model disabled by admin"); continue; }
            var info = catalog.getModelInfo(name).orElse(null);
            if (info == null) { eliminated.put(name, "model not found in registry"); continue; }
            if (isForbidden(info, profile)) {
                eliminated.put(name, "provider '" + info.getProvider() + "' forbidden by contract");
                continue;
            }
            if (!passesPolicy(info, profile)) {
                eliminated.put(name, "not in allowed list / region not supported");
                continue;
            }
            valid.add(name);
        }

        // 层级升级（TIER_ESCALATION）
        if (valid.isEmpty()) {
            String next = TIER_ESCALATION.getOrDefault(classification, "complex");
            for (String name : profile.routingPreferences().getOrDefault(next, List.of())) {
                if (!eliminated.containsKey(name) && enabled.contains(name)) {
                    var info = catalog.getModelInfo(name).orElse(null);
                    if (info != null && passesPolicy(info, profile)) valid.add(name);
                }
            }
        }

        // 兜底：全目录第一个 policy 通过者
        if (valid.isEmpty()) {
            for (var e : catalog.getActiveCatalog().entrySet()) {
                if (enabled.contains(e.getKey()) && passesPolicy(e.getValue(), profile)) { valid.add(e.getKey()); break; }
            }
        }
        if (valid.isEmpty()) valid.add("gpt-4o-mini");   // absolute fallback

        String best = scoreAndSelect(valid, profile);
        var bestInfo = catalog.getModelInfo(best).orElse(Map.of());

        String reason = buildReason(classification, bestInfo, profile);
        return new RoutingDecision(
            (String) bestInfo.getOrDefault("provider","unknown"),
            best, classification, reason, candidates, eliminated);
    }

    private boolean passesPolicy(ModelCatalogItem info, CustomerProfile profile) {
        String p = info.getProvider();
        if (profile.constraints().forbiddenProviders().contains(p)) return false;
        if (!profile.constraints().allowedProviders().isEmpty()
            && !profile.constraints().allowedProviders().contains(p)) return false;
        if (!"any".equals(profile.constraints().region())) {
            String req = profile.constraints().region().replace("-only","");
            if (!info.getRegions().contains(req)) return false;
        }
        return true;
    }

    private String scoreAndSelect(List<String> candidates, CustomerProfile profile) {
        Map<String,Double> scores = new HashMap<>();
        for (String name : candidates) {
            var info = catalog.getModelInfo(name).orElse(null);
            if (info == null) continue;
            double score = 0;
            switch (profile.objective()) {
                case "low_latency" -> score += (1.0 / Math.max(info.getAvgLatencyMs(),1)) * 10000;
                case "low_cost"    -> score += (1.0 / Math.max(info.getCostPerMInput().doubleValue(),0.00001)) * 0.01;
                case "high_quality"-> score += TIER_QUALITY.getOrDefault(info.getTier(),1) * 10;
            }
            if (info.getAvgLatencyMs() <= profile.performance().latencyTargetMs()) score += 5;
            if ("high".equals(profile.performance().costSensitivity()))
                score += (1.0 / Math.max(info.getCostPerMInput().doubleValue(),0.00001)) * 0.001;
            scores.put(name, score);
        }
        if (scores.isEmpty()) return candidates.get(0);
        return scores.entrySet().stream().max(Map.Entry.comparingByValue()).get().getKey();
    }
}
```

> `_passes_policy()` 在源里是"provider/region 过滤"，`route()` 里先调 `isForbidden` 记录原因，再 `passesPolicy` 兜底——上例为清晰起见合并为 `passesPolicy`，落地时可按源拆分以保留精确的 `eliminated` 原因文案。

@Service
public class ContractExtractionService {

    private final ChatClient chatClient;               // Spring AI
    private final OpenRouterProperties props;
    private final ModelCatalogService catalog;
    private final Resource promptTemplate;             // prompts/extraction_prompt.txt

    public CustomerProfile extractProfile(String customerName, String contractText, String customInstructions) {
        // 组装 prompt（沿用源 EXTRACTION_PROMPT 模板 + models_by_tier + providers）
        String modelsByTier = buildModelsByTier(catalog.getActiveCatalog());
        String availableProviders = String.join(", ", catalog.getProviders());
        String prompt = promptTemplate  // 模板占位替换
                .replace("{contract_text}", contractText)
                .replace("{custom_instructions}", customInstructions == null ? "None" : customInstructions)
                .replace("{models_by_tier}", modelsByTier)
                .replace("{available_providers}", availableProviders);

        try {
            String content = chatClient.prompt()
                    .user(prompt)
                    .call()
                    .content();                          // 等价于源 httpx 调用 + 解析 content
            content = stripMarkdownCodeBlock(content);   // 去除 ``` 代码块
            return parseProfileJson(content, customerName);
        } catch (Exception e) {
            log.error("Extraction failed: {}", e.getMessage());
            return loadFallback(customerName)            // _load_fallback 平移
                    .orElseThrow(() -> new ApiException(500, "Extraction failed"));
        }
    }
}
```

> Spring AI 的 `ChatClient` 已配置 `temperature=0.0`、`max-tokens=1200`、model=`openai/gpt-5.4`，对应源 extractor 的调用参数。

### 7.1 `ProxyController`（核心，保真最关键）

```java
@RestController
public class ProxyController {

    private final RoutingEngineService router;
    private final ModelCatalogService catalog;
    private final ContractExtractionService extraction;  // 备用
    private final RequestLogProducer logProducer;

    private static final Map<String,String> TIER_MODEL_MAP = Map.of(
        "modelgate-simple","simple", "modelgate-medium","medium", "modelgate-complex","complex");

    // GET /{customer_id}/v1/models  —— OpenAI 兼容模型列表
    @GetMapping("/{customerId}/v1/models")
    public ResponseEntity<Map<String,Object>> listModels(@PathVariable String customerId) {
        CustomerProfile profile = customerRepo.get(customerId)
            .orElseThrow(() -> new ApiException(404, "Customer '"+customerId+"' not found"));
        long created = profile.createdAt().getEpochSecond();
        List<Map<String,Object>> models = new ArrayList<>();
        models.add(openAiModel("auto", created, "Automatic routing"));
        for (String tier : profile.routingPreferences().keySet()) {
            models.add(openAiModel("modelgate-"+tier, created, "Service tier: "+tier));
        }
        return ResponseEntity.ok(Map.of("object","list","data",models));
    }

    // POST /{customer_id}/v1/chat/completions
    @PostMapping("/{customerId}/v1/chat/completions")
    public ResponseEntity<Map<String,Object>> chatCompletions(
            @PathVariable String customerId,
            @RequestBody @Valid ChatCompletionRequestDto request) {
        CustomerProfile profile = customerRepo.get(customerId)
            .orElseThrow(() -> new ApiException(404, "Customer not found"));

        String userPrompt = extractLastUserMessage(request.messages());
        if (userPrompt.isBlank()) throw new ApiException(400, "No user message found");

        long classifyStart = System.currentTimeMillis();
        RoutingDecision decision = router.route(profile, userPrompt,
            TIER_MODEL_MAP.getOrDefault(request.model(), null));
        int classifyMs = (int)(System.currentTimeMillis() - classifyStart);

        String openrouterModel = catalog.getOpenRouterId(decision.selectedModel());

        // 转发 OpenRouter（用 Spring AI 或 RestClient）
        Map<String,Object> result = openRouterClient.chatCompletions(
            openrouterModel, request.messages(), request.temperature(), request.maxTokens());

        int latencyMs = (int)(System.currentTimeMillis() - classifyStart);
        long inTokens = tokenCount(userPrompt), outTokens = 100;   // 从 usage 解析
        BigDecimal cost = catalog.estimateCost(decision.selectedModel(), inTokens, outTokens);

        // 异步写日志（Kafka）
        logProducer.sendRequestLog(buildLogEntry(customerId, userPrompt, decision, latencyMs, cost, "success"));

        HttpHeaders headers = new HttpHeaders();
        headers.add("X-Routing-Decision", objectMapper.writeValueAsString(routingMeta(decision, latencyMs, classifyMs, cost)));
        headers.add("X-Model-Used", decision.selectedModel());
        headers.add("X-Classification", decision.classification());
        headers.add("X-Latency-Ms", String.valueOf(latencyMs));
        headers.add("X-TTFT-Ms", "0");
        headers.add("X-Classify-Ms", String.valueOf(classifyMs));
        headers.add("X-Cost", cost.toPlainString());

        return ResponseEntity.ok().headers(headers).body(result);   // 透传 OpenAI 响应体
    }
}
```

> **保真红线**：`X-Routing-Decision`（JSON）、`X-Model-Used`、`X-Classification`、`X-Latency-Ms`、`X-TTFT-Ms`、`X-Classify-Ms`、`X-Cost` 7 个响应头 + OpenAI 响应体结构，必须与源 [proxy.py](../backend/routers/proxy.py) 完全一致（前端 `api.ts` 依赖它们）。建议用 spring-cloud-contract 写契约测试锁定。
