# 前端界面中文化清单（ModelGate）

> 目标：将 `frontend/` 下 Next.js 前端的全部英文 UI 文案改为中文。
> 原则：**只改展示文案，不改业务逻辑、不改接口调用、不改数据结构、不改路由路径**。`/`、`/customers`、`/models`、`/playground` 等路由地址保持不变（避免影响导航与外部链接）。

---

## 十一、实施建议

### 11.1 处理顺序（建议按依赖）
1. `layout.tsx`（页面标题）→ 2. `Sidebar.tsx`（全局导航）→ 3. `page.tsx`（Dashboard）→ 4. `customers/*`（客户三页）→ 5. `models/page.tsx` → 6. `playground/page.tsx`。

### 11.2 关键注意点
- **不改路由**：所有 `href`、`Link`、`router.push` 保持原样。
- **不改接口**：`api.ts`、字段名、props 名称不动。
- **数据值中文化建议用映射**：在后端或前端维护字典，例如：

```ts
const TIER_LABELS: Record<string, string> = { simple: "简单", medium: "中等", complex: "复杂" };
const OBJECTIVE_LABELS: Record<string, string> = { low_latency: "低延迟", high_quality: "高质量", low_cost: "低成本" };
const SEVERITY_LABELS: Record<string, string> = { critical: "严重", warning: "警告", info: "提示" };
```

- **避免硬编码污染**：对 `simple/medium/complex`、`low_latency/high_quality/low_cost`、隐私等级、severity 等枚举值，统一用映射函数（如 `tierLabel(x)`）转换，避免散落字符串。
- **数字与货币格式**：`$`、`ms`、`/M` 等单位是否替换为中文单位（如 `美元`、`毫秒`、`/百万`）可根据团队规范决定，不影响功能。
- 完成后 `npm run build` 校验无类型错误，并在浏览器中逐页人工核对。
